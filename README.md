# Propulsion

Propulsion design & analysis for GT Propulsive Landers — engine sizing codes,
feed-system analysis, thermal analysis, and supporting design literature.

## Layout

| Path | What it is |
|------|------------|
| `scripts/` | Standalone design calculators (engine design, HRE design, injector Cd, tank fill, blowdown, relief sizing, showerhead/SMD) |
| `1000N/` | 1000 N engine design files |
| `Nozzle Thermal Analysis/` | Nozzle thermal analysis |
| `Regen & Film Cooling/` | Regenerative & film cooling analysis |
| `Pressure Ladder/` | Feed-system pressure ladder |
| `OF Properties/` | Oxidizer/fuel property data |
| `VISIO P&ID Versions/` | P&ID diagram versions |
| `Design Literature/` | Reference papers & design literature |

## Scripts

The `scripts/` directory contains:

- `Engine Design Code Fixed Configuration.py`
- `HRE Design Code Fixed OF.py`
- `HRE Design Code Optimal Isp.py`
- `Injector Cd Calculator.py`
- `Showerhead Orifice & SMD Calculator.py`
- `Tank Fill Mass Calculator.py`
- `GN2 Blowdown Source Check.py`
- `API 520 D2.2 Subcooled Liquid Relief Sizing.py`
